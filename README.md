# MultBilim Animation Studio

MultBilim animatsiya studiyasi uchun ishlab chiqilgan zamonaviy, responsive va to‘liq funksional demo sayt.

**Jonli demo:** [multbilim-studio-demo.nosirbekxakimov01.chatgpt.site](https://multbilim-studio-demo.nosirbekxakimov01.chatgpt.site)

## Imkoniyatlar

- original loyihalar va har biri uchun alohida batafsil sahifa;
- YouTube’ga o‘tmasdan sayt ichida video tomosha qilish;
- dark va light rejimlar;
- yumshoq scroll hamda mikroanimatsiyalar;
- xizmatlar, ishlab chiqarish jarayoni, texnologiyalar va jamoa bo‘limlari;
- karyera, FAQ va loyiha muhokamasi formasi;
- foydalanuvchi roziligiga asoslangan anonim analitika;
- himoyalangan professional admin dashboard;
- telefon, planshet va katta ekranlar uchun moslashuvchan dizayn.

## Texnologiyalar

- React 19
- TypeScript
- vinext / Vite
- Cloudflare Workers
- Cloudflare D1
- Drizzle ORM

## Mahalliy ishga tushirish

Node.js `22.13.0` yoki undan yangi versiya kerak.

```bash
npm install
npm run dev
```

Build tekshiruvi:

```bash
npm run build
```

## Hosting haqida

Sayt server funksiyalari, D1 analitika va autentifikatsiyadan foydalanadi. Shu sababli to‘liq versiyani GitHub Pages emas, Cloudflare yoki boshqa serverless platformada joylashtirish kerak. GitHub repository kod tarixi va hamkorlik uchun ishlatiladi.

## Maxfiylik

Analitika faqat tashrifchi rozilik berganidan keyin ishlaydi. IP manzil, ism, telefon yoki email analitika bazasida saqlanmaydi. Admin panel alohida autentifikatsiya va email allowlist bilan himoyalangan.
