MultBilim animatsiya studiyasi uchun ishlab chiqilgan premium, zamonaviy va to‘liq funksional korporativ veb-sayt demosi.

## Mahalliy ishga tushirish

### Talablar

- Node.js `22.13.0` yoki undan yangi;
- npm;
- Git.

### O‘rnatish

```bash
git clone https://github.com/XakimovNosirbek/multbilim-studio.git
cd multbilim-studio
npm install
npm run dev
```

Development server odatda `http://localhost:3000` manzilida ochiladi.

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

```bash
npm run db:generate
```

Mahalliy D1 konfiguratsiyasi loyiha ichidagi Vite va Sites sozlamalari orqali boshqariladi. Production database credential yoki real resource ID repository ichida saqlanmaydi.

## Analitika qanday ishlaydi?

1. Tashrifchiga maxfiylik banneri ko‘rsatiladi.
2. Tashrifchi analitikani qabul qilsa, qurilmada anonim UUID yaratiladi.
3. Sahifa almashganda `/api/analytics` endpoint’iga anonim hodisa yuboriladi.
4. Server kelgan qiymatlarni tekshiradi va D1 bazaga yozadi.
5. Admin dashboard server tarafida umumlashtirilgan statistikani hisoblaydi.
6. 13 oydan eski tashriflar yangi yozuv kelganda o‘chiriladi.

Saqlanadigan ma’lumotlar:

- anonim visitor ID;
- tashrif vaqti;
- ochilgan path;
- referrer origin;
- brauzer tili;
- desktop/tablet/mobile turi;
- vaqt mintaqasi;
- consent versiyasi.

Saqlanmaydigan ma’lumotlar:

- IP manzil;
- ism yoki familiya;
- telefon;
- email;
- aniq geografik manzil;
- reklama profili.

## Admin xavfsizligi

`/admin` oddiy public dashboard emas. U ikki qatlam bilan himoyalangan:

1. server tarafidagi foydalanuvchi autentifikatsiyasi;
2. `MULTBILIM_ADMIN_EMAILS` environment qiymatidagi email allowlist.

Admin ruxsati frontend JavaScript’iga ishonmaydi. Ruxsatsiz foydalanuvchiga dashboard ma’lumotlari server tomonidan berilmaydi. Environment qiymatlari GitHub repository’ga yozilmaydi va hosting platformasida boshqariladi.

## Hosting va domen

Repository public bo‘lsa ham, to‘liq saytni **GitHub Pages’da joylashtirish tavsiya etilmaydi**. GitHub Pages statik hosting bo‘lgani uchun quyidagilar ishlamaydi:

- D1 database;
- `/api/analytics` server endpoint’i;
- server-side admin autentifikatsiyasi;
- real dashboard so‘rovlari;
- server tomonidan generatsiya qilinadigan dinamik sahifalar.

Tavsiya etilgan model:

```text
GitHub repository → source code va hamkorlik
Cloudflare/Sites   → production sayt, server, D1 va admin
Custom domain      → multbilim.uz yoki tanlangan rasmiy manzil
```

Rasmiy domen olingach, DNS orqali mavjud deployment’ga ulanadi. HTTPS sertifikat avtomatik chiqariladi; kod, analitika va admin panelni qayta yozish talab qilinmaydi.

## Telegram boshqaruvi

Telegram admin-bot backend’i loyiha tarkibiga kiritilgan. Bot faqat ruxsat berilgan Telegram ID’lariga javob beradi va webhook so‘rovlari maxfiy kalit bilan tekshiriladi.

Bot imkoniyatlari:

- tugmali boshqaruv menyusi;
- bugungi, 7 kunlik va 30 kunlik analitika;
- mashhur sahifalar va qurilmalar hisoboti;
- yangi loyiha briefi kelganda tezkor bildirishnoma;
- so‘nggi brieflar va o‘qilmaganlar soni;
- sayt holati va himoyalangan web-admin havolasi.
- Telegram ichida ochiladigan responsive Mini App dashboard;
- Mini App foydalanuvchisini serverda Telegram `initData` imzosi orqali tekshirish.

Production sozlamalari GitHub’da emas, hosting environment’ida saqlanadi: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_IDS`, `TELEGRAM_WEBHOOK_SECRET` va `PUBLIC_SITE_URL`. Webhook manzili: `/api/telegram/webhook`.
